# create-ip-op-poster-skill

一份制作中文 IP／OP 招商海报的通用 Agent Skill。它先确认人物素材，再根据 Brief 选择创意方向和生成模式，确认完整 Prompt 后只生成一次正式海报。

## 最简单的用法

开始时，Skill 会先解释素材用途：人物肖像素材好，整张海报的呈现才会好；案例图则用于读懂达人真实内容里的场景、叙事、人物关系、笑点／反转和账号记忆点，让玩法更贴合达人，而不是悬浮套模板。

第一次至少上传人物／动物原图；最好同时给每位达人 1–3 张代表案例截图，然后发送：

```text
请使用 $create-ip-op-poster，先处理并让我确认人物素材，不要直接做海报。
```

Agent 会先提供横版白底人物组合预览，并同步保留透明底总图，以及每个人物／动物或不可拆原始组合的独立透明抠图。检查满意后回复：

```text
人物素材通过
```

案例图不一定要放进最终海报，也可以在人物确认后再补。没有案例时，可用账号主页截图、代表作链接或账号介绍代替；都没有也能继续，但 Skill 会明确提示玩法与达人内容的贴合度有限。

随后再提供 Brief、案例截图、Logo 和具体建议。选择创意方向和模式，例如：

```text
选方向 1，用模式 B
```

查看完整文字 Prompt 后回复：

```text
确认生成
```

新版没有独立的人物排布确认稿，不会为了确认布局多生成一张接近成稿的海报。

## 两种生成模式

- **模式 A｜快速生图：** 生图模型直接完成整张海报，通常更快、更统一；人物、截图、Logo 和中文可能被重新绘制，不能承诺像素保真。
- **模式 B｜保真合成：** 生图模型先生成完整的 PNG、WebP 或 JPEG 艺术底图，再把确认过的人物、截图、Logo 和中文作为保护图层覆回。程序只能在生图底图产生后做合成，不能用 SVG、HTML、PPT 或色块网格生成底图。

## 在 Codex 安装

在 Codex 中发送：

```text
请使用 $skill-installer，从 https://github.com/nmmg0112/create-ip-op-poster-skill 安装根目录 Skill，并命名为 create-ip-op-poster。
```

安装后重新启动 Codex。如平台不支持文件式 Skill，可使用[普通 AI 会话启动语](examples/chatgpt-starter.md)。

## Skill 会做什么

- 用用户提供的原图处理人物／动物素材，不改变身份特征；
- 根据任意行业、季节或节点 Brief 提供真正不同的创意方向；
- 为单人达人设计专属玩法，或按内容和商业逻辑组织多人矩阵；
- 从视觉案例学习结构、密度和气质，不照抄具体作品；
- 在快速生图与保真合成之间说明真实取舍；
- 检查第一视觉、景深、信息层级、人物与玩法关系，以及截图和 Logo 完整性；
- 拦截 PPT 感、程序化信息板、无意义空白和重复生图。

## 不可违反的规则

- 两种模式都必须先让用户确认人物素材。
- 人物素材处理阶段不能新增、遗漏、重复或改变人物／动物身份。
- 模式 B 中，案例截图不能改字、改数据、裁切或重绘，Logo 必须保留全部元素；模式 A 必须先逐项披露可能发生的生成式重绘，不能声称原样保留。
- 模式 B 的底图必须来自生图模型，而不是 SVG、HTML、PPT、Canvas、Sharp 或固定网格。
- 没有生图能力时只能输出 Prompt 或交接包，不能用程序化页面冒充成稿。
