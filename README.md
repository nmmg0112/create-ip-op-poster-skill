# create-ip-op-poster-skill

给第一次使用 Agent 的人做中文 IP／OP 招商海报。上传完整 Skill 包后只说一句话，Skill 会自动说明用法；你只需要准备素材、看两次结果，其余判断由 Skill 完成。

## 最简单的开始方式

上传完整 Skill 压缩包，然后发送：

```text
请读取这个 Skill，告诉我怎么使用，并带我开始制作一张海报。
```

不要求用户复制长 Prompt。Skill 被读取后自动发送一次新手开场白，解释人物和案例为什么重要，并给出：

```text
【主题／Brief】
【喜欢的风格】不知道可以写“你推荐”
【文字密度】少／中／多
【必须出现的文字】
```

多人示例：4 位达人｜运动赛事主题｜红蓝对撞、大片感、高张力｜中等文字密度。资料不全也没关系，先发人物图片即可。

### Aime 评委体验

Aime 使用 Image2。Skill 会先收拢当前需求，再把一个锁定版本交给 Image2，不把零散聊天直接塞给生图模型。

### 豆包体验

豆包会自动尝试调用 **Seedream 5.0 Pro**，在生图前告诉你本次实际模型；你不需要复制模型链接或长指令。若 5.0 Pro 暂时不可用，Skill 会先说明换用其他模型可能影响人脸、中文、案例和整体设计，再让你决定是否继续，不会悄悄降级。

豆包默认使用已经验证更稳定的杂志编辑式方向：**大标题＋人物主视觉＋案例拼贴＋玩法说明**。这不是固定模板，颜色、材质、标题和构图仍会随 Brief 改变；玩法也不限制为一句话，会按内容需要保留一至三行。

## 四步就能用

### 1. 上传人物

先发人物／动物原图。人物肖像素材好，整张海报的呈现才会好；清晰、真实、有表现力的照片，才能让人物成为第一视觉。

案例图也建议一起发。它不是装饰，而是帮助 Skill 看懂达人真实内容里的场景、人物关系、笑点、反转和账号记忆点，让玩法不悬浮。没有案例时，也可以给账号主页截图、代表作链接或账号介绍；这些都没有仍可继续，但玩法贴合度有限。

### 2. 确认人物预览

Skill 会先给你一张横版白底人物组合图。只检查有没有变脸、漏人、重复、身体误删或明显抠图残边，不用判断最终海报排版。如果你还没说 **视觉偏好（可选）**，它会在这条消息里顺带问一句颜色或感觉；不回答也没关系。

确认无误后回复：

```text
人物没问题
```

### 3. 补 Brief 和案例，选择方案

把项目 Brief、案例、Logo、固定文案和具体建议发给 Skill。你在人物确认时写了颜色或感觉，它会和 Brief 一起使用；只回复了“人物没问题”，它就直接结合 Brief 推荐，不会再单独等待。

Skill 会给出一个推荐方案和一个真正不同的备选方案。每个方案都会写清楚：谁来做、在什么场景、怎么互动或反转、产品怎样自然进入，以及海报怎么表现。

### 4. 直接生成

选择推荐方案时回复：

```text
选 1 生成
```

这句话同时代表选定方案并允许生图。默认使用 **16:9 横版**，直接完成一张包含主题、人物、具体玩法、案例和商务信息的完整海报；不会先做空底图、排布稿或第二张重复海报。

## 两个确认

正常只确认两次：

1. `人物没问题`：确认人物素材可用；
2. `选 1 生成`：确认内容方案并直接生成。

不用选择技术路线，也不用阅读或批准长 Prompt。想看内部执行指令时可以主动提出，但不新增确认门槛。

## 默认整图生成与严格保真

**默认整图生成**追求更统一、更好看的完整画面，会最大程度保持人物和案例，但可能出现细节变化，**不承诺逐像素**完全一致。

只有你明确说“人脸、案例截图、Logo、数据或固定中文必须完全不变”时，Skill 才会在后台启用**严格保真**。你不需要理解或选择制作方式；如果当前工具做不到，它会给出方案、Prompt 和素材映射的交接包，不拿低质量版本冒充成稿。

成图后如果只需增加 Logo、修改准确中文、报价、权益、案例或一个元素，必须局部修改，**不得整图重绘**，避免其他人物和内容跟着变化。

开场白只出现一次。用户已经给出素材或需求时，Skill 会直接整理，不会再单独等待用户重填模板。

## 安装

在 Codex 中发送：

```text
请使用 $skill-installer，从 https://github.com/nmmg0112/create-ip-op-poster-skill 安装根目录 Skill，并命名为 create-ip-op-poster。
```

安装后重新启动 Codex。ChatGPT、豆包、Coze 等不能安装文件式 Skill 的平台，上传完整压缩包后按[普通会话平台说明](examples/chatgpt-starter.md)发送一句话即可。

## Skill 会自动检查

- OP／招商主海报必须是 16:9 横版；只有明确的竖版渠道或适配用途才改变；
- 正式生成前必须有具体内容玩法，不能只有口号和“高级感”；
- 人物是视觉主体，且必须和玩法发生关系；
- 不能做成 PPT、后台页面、头像网格或空背景；
- 不能漏人、重复、乱改数据或虚构客户、报价和权益；
- 最终图片必须能正常打开和预览。
