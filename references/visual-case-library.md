# 视觉案例库（公开匿名版）

## 用途与边界

这是视觉案例库，不是可直接使用的素材库。公开版本只保留匿名编号和抽象视觉语法，不包含内部来源、机构名、客户名或案例文件名。

案例只能帮助判断信息层级、人物尺度、分组、密度、颜色分工和商业海报语法。不得把参考图或其中元素直接放入新海报；不得复制标题、文案、Logo、印章、专属容器、具体人物排布或标志性装饰。

## 检索方法

每次选择 2—4 张互补案例：

1. 先匹配内容关系和版式家族；
2. 再匹配单人／矩阵结构与人物数量；
3. 再匹配玩法和信息复杂度；
4. 最后才看表面颜色与风格。

至少包含结构参考；中高密度项目再加入密度参考；需要明确气质时加入气质参考。同一案例最多承担两个角色，并且要再选一张结构不同的案例。

每张案例记录：

- 参考角色：结构、密度或气质；
- 可借鉴的抽象语法；
- 当前项目必须做出的差异；
- 禁止复制的具体元素。

## 抽象语法提示

- 概念场景：让一个当前 Brief 专属的场景或隐喻统一整页。
- 群像主视觉：标题与人物共同建立第一视觉，证据退居第二层。
- 玩法分舱：每个玩法拥有自己的人物、机制和案例证据。
- 路线阶段：只在内容确有先后、接力或阶段关系时使用。
- 矩阵档案：用编号、网格、颜色编码和稳定对齐承载复杂映射。
- 编辑拼贴：用不对称尺度、场景切片和材质变化建立节奏，但必须保留清楚的阅读锚点。
- 高密度不等于小字：优先使用分组、编号、重复对齐和尺度差建立可扫描性。
- 人物必须进入对应玩法或场景，不能成为与内容分离的悬浮贴纸。
- 表面颜色和材质不能由行业标签直接决定，必须回指当前 Brief、人物／账号证据、品牌规则、受众情绪或内容机制。
