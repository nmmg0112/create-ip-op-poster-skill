## 1. Purpose and restrictions

The core 24 authorized reference images come from the Feishu Wiki section `各行业/节点优秀IP案例`. Additional user-supplied references may be appended with their provenance noted. This is a visual-example library, not a material library. Use it to understand information hierarchy, creator scale, grouping, density, color roles, and commercial-poster grammar.

Never place these images or extracted elements into a user's poster unless the user separately supplies them as approved case screenshots. Never copy a case's title, copy, composition, Logo, seal, decoration, or distinctive motif.

## 2. Retrieval protocol

Choose only 2–4 cases for a task:

1. Match industry or marketing-node function.
2. Match single/matrix structure and approximate creator count.
3. Match information/play complexity.
4. Use surface color/style only as the final filter.

For each chosen case, write:

- `borrowed grammar`: an abstract layout or hierarchy principle;
- `intentional differences`: how the new poster will respond to the current brief instead;
- `forbidden copy elements`: concrete case-specific elements that must not appear.

If one reference dominates the resulting idea, add a structurally different reference or restart the direction.
