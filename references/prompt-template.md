# 项目级完整海报 Prompt 模板

## 使用方法

只使用已经通过 `人物素材通过`、已选定方向与模式的事实和素材。先把人物／动物、案例截图、Logo 和固定文案分别编号为 `P`、`C`、`L`、`T`，再填写共享部分与所选模式的生产部分。

- 完整 Prompt 确认是纯文字轮次，不调用生图模型，也不消耗正式海报生成次数。
- 删除不适用的章节，不写“无”；替换全部尖括号占位后再展示。
- 用户提供的名称、固定文案和截图文字必须逐字保留，不得润色。
- 白底人物组合图只证明人物素材可用，不是最终排版依据。最终构图由已选方向、本模板的构图语法和资产映射共同定义。
- “高级感、商业感、科技感”等抽象词必须落到场景、颜色、材质、光影、景深、尺度、动势或装饰规则。
- `P/C/L/T` 在模式 A 中是可能被模型重绘的参考项；在模式 B 中是生图底图必须避开、随后由原始素材覆回的保护项。不能混写两种保真承诺。
- 默认只调用一次正式生图。失败后先报告问题和可修范围，不自动消耗第二次生成。

【参考边界】

【美观预检】

- 标题、人物、玩法和证据形成大小节奏，不是等权卡片网格或 PPT 信息板。
- 每块主要留白都有聚焦、分隔、呼吸或引导用途。
- 前景、中景和背景完整，材质、光影与交叠形成空间深度。
- 装饰只服务当前视觉母题，不用行业套路或无关元素填空。

【共享负面要求】
不要新增、漏掉或重复人物／动物；不要拆散不可分的原始组合；不要遮挡脸部或动物头部；不要密集小字；不要留下无意义空白；不要把人物与玩法分离；不要做等权卡片墙、头像网格、PPT 页面、线框稿或规则色块页；不要虚构事实；不要照抄参考；不要擅自添加直播、短直联动、品类列表或其他未确认的合作方式；不要把文件名后缀当作达人昵称。

## 模式 A 生产段

把以下部分接在共享 Prompt 后。必须逐项列出允许发生生成式重绘的资产，不能用一句笼统免责声明代替。

```text
【模式 A｜端到端整图生成】
将已确认人物素材作为主要人物参考，由生图模型一次完成整张海报。输出一张完整海报预览，包含主题、人物、玩法、场景、背景、构图、材质、光影、前中后景、装饰语言和视觉动势。

允许发生生成式重绘的参考项：
P：<逐项列出允许模型参考并重绘的人物／动物 ID>
C：<逐项列出可能被模型近似重绘的截图 ID；不允许则删除并改选模式 B>
L：<逐项列出可能被模型近似重绘的 Logo ID；不允许则删除并改选模式 B>
T：<逐项列出希望出现但可能错字、乱码或变形的中文 ID；必须逐字准确则改选模式 B>

本模式不承诺人物、动物、截图、Logo 或中文的像素保真。不得在结果说明中声称任何由模型生成的 P/C/L/T 是原像素、原图覆回或严格保真。仍需检查人员数量、主题、玩法关系、中文可读性、商业海报审美，以及明显的脸、动物头部、Logo 或文字失败。
```

## 模式 B 生产段

共享 Prompt 后必须保留以下两个连续部分。第一段的生图输出落盘前，不得开始第二段。

```text
【模式 B｜第一段：主视觉位图生成 Prompt】
第一项生产动作必须调用生图模型，直接生成一张完整的 PNG、WebP 或 JPEG 艺术底图，作为完整海报预览和后续合成的唯一视觉底座。

底图必须包含完整背景场景、构图、材质、光影、前景、中景、背景、装饰语言和视觉动势；即使暂时没有受保护图层，也必须呈现成熟商业招商海报的艺术层级，而不是素材摆放说明。

为以下 P/C/L/T 保护图层留下自然、具体、与场景融合的位置和必要遮挡关系，但不要生成、描摹、仿制或写出其受保护内容：<逐项列出 ID、角色、位置、尺度、景深、光影接口与安全区>。

不得输出 SVG、HTML、Canvas、PPT、Sharp 绘图、线框稿、布局示意图、规则色块页、头像网格、等权卡片墙或程序化信息板。不得先运行 SVG、HTML、Canvas、PPT 或任何代码绘图来创建、代替、描摹或栅格化这个底图。扩展名为 PNG／WebP／JPEG 但来源是程序绘图的文件仍然不合格。

输出要求：<PNG | WebP | JPEG>，<像素尺寸>，无受保护人物、截图、Logo 和固定中文的仿制内容；保留可以自然覆回它们的空间、景深、接触面、光线方向和视觉连接。

【模式 B｜第二段：保护图层合成说明】
只有在上述生图模型产出的位图已经落盘并记录来源后，才在该位图底图上覆回透明人物总图或独立透明抠图、完整案例截图、原 Logo 和准确中文。

代码只负责蒙版、等比缩放、位置、层级、非破坏性阴影衔接、文字栅格化、格式转换、导出和验证。代码不得创建、替换或大面积重绘艺术底图；不得用固定矩形、网格、Canvas、SVG、HTML、PPT、Sharp 命令或其他程序绘图补做主视觉。

保护图层映射：
P：<ID -> 使用 master_transparent 或 subjects_transparent -> 位置／尺度／层级／安全区>
C：<ID -> 原文件 -> 完整显示位置／尺度／层级>
L：<ID -> 原文件 -> 位置／尺度／层级>
T：<ID -> 完整原文 -> 字体／字号／位置／层级／栅格化方法>

完成 Logo、文字或截图的精确后期修改时，只替换目标独立图层并验证其他区域未变化。不得为精确改动把整张成稿再次送入生图模型。

生产回执必须包含：
visual_base_path: <位图底图路径>
visual_base_format: <PNG | WebP | JPEG>
image_generation_model_or_tool: <生图模型或工具记录>
visual_base_created_before_composite: <有直接先后证据才写 true>
protected_layer_ids: <实际覆回的 P/C/L/T ID>
formal_generation_count: <正式生图调用次数，默认 1>
```

## 输出与验收段

在所选模式生产段末尾追加：

```text
【输出与验收】
- 输出：<文件格式、分辨率和是否需要可编辑源文件>。
- 人物／动物数量与素材台账一致，无新增、重复或遗漏。
- 主题、项目背景和玩法与已确认方向一致，目标尺寸下可读。
- 第一视觉、尺度节奏、人物与玩法连接、前中后景和招商叙事通过视觉检查。
- 不添加未提供的粉丝量、播放量、点赞量、客户名称、合作案例、报价、权益或业务方式。
- 模式 A 按“生成参考”验收，不作像素保真声明。
- 模式 B 按位图底图来源、受保护图层完整性、合成先后顺序和非目标区域不变验收。
- 当前平台没有生图模型时，停止并输出 Prompt、素材映射和交接包；不得回退为 SVG、HTML、Canvas、PPT 或程序化信息板。
```

## 展示前检查

向用户展示完整 Prompt 前逐项确认：

- `PersonMaterialSet` 已有明确批准，白底人物图没有被误写成最终排版；
- 主题、背景、玩法、方向和所选模式一致；
- 每个 `P/C/L/T` 编号存在于台账并有明确的生成参考或保护图层角色；
- 每个玩法写明组名、成员、具体机制和人物视觉动作；
- 所有固定文案逐字保留，没有虚构事实或残留占位符；
- 场景、颜色、材质、光影、景深和装饰服务当前 Brief；
- 模式 A 明列允许重绘项和非保真披露；或模式 B 明列位图首产物、禁止程序底图、合成顺序和回执字段；
- 默认一次正式生图，完整 Prompt 确认轮次本身不生图；
- 展示的是共享部分加所选模式生产段的整份 Prompt，不是摘要。

完成检查后展示整份 Prompt，并等待用户回复 `确认生成`。只有这条明确确认才能进入生产。
