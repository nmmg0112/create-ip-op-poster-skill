# 项目级完整海报 Prompt 模板

## 使用方法

只使用已经通过方向、抠图和人物排布确认的事实与素材。先把素材台账中的人物／动物、案例截图、Logo 和固定文案分别编号为 `P`、`C`、`L`、`T`，再逐项填入模板。

- 删除不适用的章节，不写“无”。
- 完整 Prompt 展示给用户前，替换所有尖括号占位，不保留通用标签。
- 用户提供的名称、固定文案和截图文字必须逐字保留，不得润色。
- “人物是第一视觉”“人物大于文字区”等要求只在已确认方向需要时写入，不能作为所有 OP 的默认规则。
- “高级感、商业感、科技感”等抽象词必须落到颜色、材质、布局、层级或装饰规则。
- 最终 Prompt 必须把受保护素材定义为独立合成图层，明确禁止重新绘制。

## 完整 Prompt

```text
请设计一张 <已确认画幅、尺寸、行业和用途> 的招商 OP 海报。<已确认质量目标>。

【任务边界】
这是分层排版与合成任务。背景、装饰、容器和排版可以创作；人物、动物、案例截图和 Logo 是受保护图层，必须使用提供的原始素材进行合成，不允许重新绘制、近似生成或用新图替代。

【主题与背景】
项目主题：<已确认项目主题>
主题文案：<已确认主题文案>
精炼项目背景：<一到两句 Brief 或用户提供的项目事实>

【视觉导演结论】
内容关系：<并列、顺序、主次、场景、中心发散、证据、矩阵或情绪宣言，以及本项目的具体关系>
版式家族：<已确认版式家族及其适用理由>
视觉母题：<贯穿标题、背景、容器、材质和装饰的当前 Brief 专属视觉世界>
人物模式：<统一群像、按玩法分组、独立人物或主视觉人物＋辅助分组>
信息密度：<低、中或高，以及主要信息的承载方式>
第一视觉与前中后景：<第一视觉对象；前景、中景和背景分别承载什么>

【版式结构层】
画布与安全边距：<比例、像素、横／竖版和四周安全边距>
区域比例：<各区域百分比或明确的相对占比>
阅读顺序：<从第一视觉到主题、玩法、证据和底部信息的阅读路径>
第一视觉：<对象、位置、相对尺寸和视觉权重>
主要留白用途：<逐块说明留白用于聚焦、分隔、呼吸或引导，不留无意义空白>
底部区域：<高度、位置和只允许出现的合作信息或收束文案；没有则删除本行>

【玩法内容】
1. <已确认组名>
标题：<已确认标题>
成员：<逐字列出公开昵称>
一句玩法：<具体情境、角色、冲突或互动，以及产品／项目自然进入方式>
案例截图：<案例编号、数量、所属位置和排列方式；没有则删除本行>
与其他组的差异：<内容资产、场景、叙事机制或商业作用上的明确差异>

<按已确认玩法继续逐组写完整，不得合并或漏组>

【人物与动物排布】
<逐条写 P 编号 -> 公开昵称 -> 所属玩法 -> 具体位置 -> 相对大小 -> 前后层级 -> 与谁交叠 -> 脸部／动物头部安全区>
严格采用已确认的人物模式和排布。允许等比缩放、移动、前后错落和非身份区域的合理遮挡；不得遮挡脸部或动物头部，不得擅自把分组改成全员群像，也不得拆散已确认的原始组合关系。
保留每个人的脸、五官、表情、发型、服装、体型和姿势；保留动物的脸、品种、毛色、体态、姿势和辨识特征。不得新增、漏掉、重复、美颜、卡通化或重绘任何人物和动物。公开昵称不得带文件管理后缀，除非用户明确说后缀属于昵称。

【案例截图】
<逐条写 C 编号 -> 所属玩法 -> 具体位置 -> 排列方式 -> 完整显示比例>
每张截图必须作为独立矩形图层完整保留，只可等比缩放和摆放。不得裁切、改字、改数据、调色、重绘、修复或虚构；原始人物、标题和真实数据必须保持原样可辨。

【Logo】
<逐条写 L 编号 -> 具体位置 -> 排列方式 -> 相对大小>
每个 Logo 必须保留所有原始元素，只可去除背景、等比缩放和排列。不得重绘、改字、漏元素或擅自改色。

【艺术指导层】
主背景色及作用：<颜色及其承载区域、面积和作用>
标题与强调色：<颜色及其用于标题、编号或重点信息的规则>
正文色：<颜色及对比度、可读性要求>
辅助色及使用上限：<颜色、用途和最大面积／出现次数>
标题形式：<字形气质、字号关系、位置、排列和是否允许描边、底板或特殊容器>
材质与容器：<具体纸张、布料、光影、边框、卡片或场景材质，以及使用位置>
前景／中景／背景：<逐层写明人物、模块、证据、氛围和装饰的归属>
允许装饰及上限：<只列服务视觉母题的装饰，并规定数量、面积或出现区域>

【受保护图层表】
P：<逐条列出人物／动物编号、公开昵称和来源文件>
C：<逐条列出案例截图编号、所属玩法和来源文件>
L：<逐条列出 Logo 编号和来源文件>
T：<逐条列出固定文案编号、完整原文和指定位置>
以上受保护图层均用于合成，不允许重新绘制、替换或近似生成。

【固定文案与底部信息】
<逐条原样写出必须出现的固定文案、底部合作信息和收束文案>
未确认的报价、权益、客户名称、业务方式或合作内容不得出现。

【参考边界】
参考案例只用于理解信息层级、阅读路径、人物呈现、模块节奏、密度组织和视觉气质。不得复制任何参考案例的标题、文案、Logo、印章、专属容器、具体人物排布、标志性装饰或独特视觉符号。本海报必须围绕当前 Brief 重新构思。

【美观预检】
- 第一视觉明确，并与已确认方向一致。
- 人物与所属玩法关系清楚，没有孤立悬浮。
- 标题、人物、玩法模块和证据具有清楚的大小节奏。
- 每一块主要留白都有聚焦、分隔、呼吸或引导用途，不存在无意义空白。
- 前景、中景和背景层次完整，交叠不遮挡脸部或动物头部。
- 装饰只服务当前视觉母题，没有用行业套路或无关元素填空。
- 信息密度符合已确认等级；高密度内容仍能快速扫描，必要文字没有被压成小字。

【输出与验收】
- 输出：<已确认文件格式、分辨率和是否需要可编辑源文件>。
- 海报比例、尺寸、行业、用途和质量目标与本 Prompt 一致。
- 人物／动物数量与素材台账完全一致，无新增、重复或遗漏。
- 案例截图数量、所属玩法、位置和排列方式与映射完全一致，截图完整且文字、画面和数据未改动。
- Logo 数量和映射完全一致，所有元素完整。
- 固定文案逐字准确，中文清晰、无乱码或错字。
- 保持安全边距，文字和装饰不压脸、不遮挡动物头部，截图不裁切。
- 不添加未提供的粉丝量、播放量、点赞量、客户名称、合作案例、报价、权益或业务方式。
- 如果当前工具无法使用原始受保护图层进行合成，停止生成并输出图层执行说明，不得用近似重绘代替。

【负面要求】
<逐条列出当前项目禁止出现的视觉风格、业务内容和素材变化>
不要改变人物或动物身份特征；不要端到端重画人物、动物、截图或 Logo；不要密集小字；不要留下无意义空白；不要虚构事实；不要照抄参考；不要擅自添加直播、短直联动、品类列表或其他未确认的合作方式；不要把文件名后缀当作达人昵称。
```

## 展示前检查

向用户展示完整 Prompt 前逐项确认：

- 主题、背景和玩法与方向确认一致；
- 人物／动物清单与抠图确认一致；
- 人物模式、大小、分组、交叠和层级与排布确认一致；
- 每个 `P/C/L/T` 编号均存在于素材台账并有明确位置；
- 每个玩法都写明组名、标题、成员、一句玩法、案例数量和对应位置；
- 所有固定文案均逐字保留，没有改写；
- 没有虚构可选章节或事实，没有遗留尖括号占位；
- 颜色、材质、布局、景深和装饰都服务当前 Brief，而非沿用历史案例；
- 受保护图层和工具能力边界已经写明；
- 展示的是完整 Prompt，不是摘要。

完成检查后，展示整份 Prompt，并停在第 4/4 步等待用户回复“确认生成”。
