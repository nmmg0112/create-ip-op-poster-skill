# 豆包 Seedream 5.0 Pro 执行合同

本文件是豆包中的自包含执行说明。用户不需要复制长启动 Prompt，也不需要理解模型参数或平台文件。

## 自动开始

用户上传本 Skill 压缩包并说“帮我安装并告诉我怎么使用”“用这个 Skill 帮我做海报”或类似自然表达后，自动发送一次新手开场白：说明先确认人物、再选择内容与视觉方案、最后一次生成完整海报；解释人物肖像质量决定主视觉，案例截图帮助提取真实内容玩法；请用户先上传人物／动物原图，并可顺手补充主题／Brief、喜欢的风格、文字密度和必须出现的文字。

资料不全也可以先发人物。已有素材时直接整理，不重复开场白，也不强制用户按模板重填。

## 模型和执行顺序

人物素材处理和正式海报生成都使用 **Seedream 5.0 Pro**。当前会话没有启用该模型时，先用一句话请用户切换；不能用普通对话回复冒充图片生成。

```text
读取 Skill
  -> 自动开场白
  -> 建立稳定人物编号
  -> Seedream 5.0 Pro 处理人物素材
  -> 展示一张横版白底组合预览
  -> 等待“人物没问题”
  -> 读取 Brief、案例和视觉偏好
  -> 给出两个内容／视觉方向
  -> 等待“选 1 生成”
  -> 建立当前 LockedPosterSpec
  -> 编译最少充分 Prompt
  -> Seedream 5.0 Pro 正式生图一次
  -> 查看实际成图并 QA
  -> 用户通过后建立 PosterVersionLock
```

不得增加排布稿、完整 Prompt 或技术路线确认。

## 多人物输入

收到多张图片后，建立稳定人物编号：`P01、P02……`，同时记录公开昵称、每张图中的主体数量、不可拆分组合和所选版本。后续方案、Prompt 和 QA 始终使用同一映射。不得按上传顺序变化而重编号，避免漏人、重复、串脸或把文件名后缀当昵称。

人物预览只用于确认长相、数量、身体完整性、大小和边缘，不锁定最终海报排布。

## 当前锁定版本

`选 1 生成` 后建立唯一 `LockedPosterSpec`：批准人物、16:9 画幅、主题背景、玩法及成员、第一视觉、人物模式、文字密度、颜色／材质／光线／景深／动势、阅读顺序、案例／Logo／固定文字、参考语法、禁用项和正式生图次数。

正式生成只使用当前锁定版本。不要把整段聊天、已否决方案、旧要求、平台操作说明和重复禁令传给 Seedream 5.0 Pro。用户改变主题、玩法、整体风格或构图时先生成新版本，不能把新旧方向混合。

## 生图与 QA

- 默认正式生图一次，输出一张 16:9 横版完整招商海报。
- 不生成竖版、排布稿、空底图、头像网格、PPT 信息页或第二张重复海报。
- Prompt 必须先写具体内容玩法和人物关系，再写完整艺术场景、第一视觉、文字密度、前中后景和少量禁令。
- 多人不能全部等大平铺；单人必须有唯一人物焦点，简洁但不能空。
- 实际查看最终图片；竖版、无玩法、像 PPT、画面空、错脸、漏人、重复、串脸、中文乱码或案例严重变化均为失败。

当前豆包会话不能使用 Seedream 5.0 Pro、多图参考、图片编辑或所需严格保真能力时，明确说明限制并交付当前锁定规格，不生成低质量替代品。

## 成功版本保护

用户通过第一版后建立 `PosterVersionLock`，保留上一版成功文件。改名字、Logo、固定中文、报价、权益、案例或单个标签时只做局部修改，不得整图重绘；豆包无法局部修改时直接说明。整体风格、背景、主题或人物组合变化时，保留旧版并创建新的整体版本。
