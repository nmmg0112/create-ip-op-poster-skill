# 视觉导演

视觉导演在创意方向输出前运行一次，在最终 Prompt 输出前再次运行。它先判断信息关系和视觉秩序，再决定表面风格；行业和节点只提供约束，不能直接替代创意判断。

## 六项必做判断

每个项目都要记录以下六项，不得只写“高级感”“商业感”或“科技感”等无法执行的形容词。

1. **内容关系**：并列、顺序、主次、场景、中心发散、证据、矩阵或情绪宣言。
2. **版式家族**：概念场景、群像主视觉、玩法分舱、路线阶段、矩阵档案、编辑拼贴，或有充分理由的新结构。
3. **视觉母题**：用一个当前 Brief 专属的视觉世界统一标题、背景、容器、材质和装饰；不能用行业套路代替母题。
4. **人物模式**：统一群像、按玩法分组、独立人物、主视觉人物＋辅助分组。
5. **信息密度**：低、中或高；说明为什么适合当前内容，并为每一块主要留白写明用途。
6. **层级与景深**：写明第一视觉、第二层玩法、第三层证据，以及前景、中景、背景的关系。

## 表面风格的证据门槛

行业标签本身不是表面风格证据。颜色、材质、信息容器和装饰母题必须逐项说明依据，并且每一项至少引用以下一种当前项目证据：

- Brief 原文中的主题词、场景词或动作词；
- Brief 明确描述的受众情绪；
- 已提供的人物、账号内容或案例证据；
- 已提供的品牌规范、产品视觉或指定色；
- 已确认的内容机制、人物关系或剧情动作。

不得自动套用“数码＝科技蓝／霓虹／玻璃／UI／控制台”，也不得用其他行业刻板印象替代证据。若某个颜色、材质、容器或装饰无法指向以上证据，就删除或重新选择；“符合行业”“有科技感”“更商业”不算依据。

推荐方向必须以 Brief 专属的人物行动或内容机制作为视觉母题，例如谁在什么场景中完成什么动作、互动或冲突，而不是以行业表面符号命名。若未提供达人或账号细节，只能使用 Brief 已写明的场景、人物关系、受众情绪或内容机制；这些也缺失时，先给出中性的内容结构并标出待补信息，不能用行业默认风格补空白。

## 互补参考

每次从视觉案例库选择 2—4 张互补案例，不按“看起来相似”机械匹配：

- **结构参考**：学习阅读路径、区域关系和人物与玩法的连接方法。
- **密度参考**：学习如何用编号、对齐、颜色编码和重复模块承载信息。
- **气质参考**：学习色彩关系、材质、标题能量和画面情绪。

同一案例最多承担两个角色，并且必须再选一张结构不同的案例。每张案例记录：

| 字段 | 记录内容 |
|---|---|
| 参考角色 | 结构参考、密度参考或气质参考 |
| 可借鉴抽象语法 | 阅读路径、层级、节奏、分组或颜色分工 |
| 本次差异 | 当前 Brief 下必须改变的结构或表达 |
| 禁止复制元素 | 标题、文案、Logo、印章、专属容器、具体人物排布、标志性装饰或独特符号 |

如果一个参考案例已经主导了标题、容器和构图三项，立即加入结构不同的案例重新判断，不能在原案例上只换颜色和文案。

## 六类版式

- **概念场景**：一个行业、节点或内容隐喻贯穿整页，模块嵌入同一视觉世界。
- **群像主视觉**：标题与人物共同建立第一视觉，适合一个共同承诺或清晰主次。
- **玩法分舱**：每个玩法拥有自己的人物、机制和证据，不强制先做全员群像。
- **路线阶段**：只在内容确有先后、路径、接力或阶段关系时使用。
- **矩阵档案**：用稳定网格、编号和颜色编码承载复杂映射与高密度证明。
- **编辑拼贴**：用非对称尺度、场景切片和材质变化建立节奏，必须保留清楚的阅读锚点。

当以上六类都不适合时，可以提出新结构，但必须说明内容关系、阅读顺序、区域分配、第一视觉和它优于六类版式的原因。

## 方向输出前检查

每个创意方向都必须写清：

- 内容关系；
- 版式家族与阅读顺序；
- 大致区域分配；
- 第一视觉；
- 信息密度；
- 视觉母题与颜色分工；
- 人物与玩法映射；
- 已提供案例或数据的位置；
- 主要留白的用途；
- 最大构图风险。

其中“视觉母题与颜色分工”必须附带简短证据标注，至少能回指 Brief 原文、受众情绪、人物／账号证据、品牌规则或内容机制之一。推荐方向还必须额外写出一句“人物行动／内容机制母题”，说明画面的具体人味和内容感从哪里来。

当版式尚未确定时，2—3 个方向必须使用真正不同的结构，不能只换标题、颜色或装饰。

## 美观预检

在方向确认前和最终 Prompt 输出前各检查一次：

- 第一视觉是否明确，用户能否在一秒内知道先看哪里。
- 人物是否进入对应玩法，而不是与玩法区分离。
- 主要留白是否都有用途，例如承托标题、隔开模块或形成视线方向。
- 标题、人物、模块是否有清楚的大小节奏，避免所有元素等大。
- 是否形成前景、中景和背景，而不是所有元素贴在同一平面。
- 装饰是否服务视觉母题，删除后若不影响理解则应克制使用。
- 高密度信息是否仍可按标题、玩法、证据快速扫描。
- 是否出现行业套路，例如“数码＝蓝色霓虹科技界面”“中秋＝卷轴、印章和满月”。

任一项失败时，先修正方向或排布，不生成最终 Prompt。修正时优先调整内容关系、区域比例、尺度和景深，再考虑增加装饰。
