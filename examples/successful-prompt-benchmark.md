# 成功 Prompt 基准：夏夜开黑事务所

## 用途

这是一个**完全虚构**的公开示例，用来说明后台执行 Prompt 怎样做到“篇幅不过长，但画面所需信息完整”。成功基准是：主题明确、玩法能拍、人物和案例各有视觉角色、构图有艺术关系、配色有 Brief 依据，且商务信息与关键禁令清楚。

## 不得固化

不得把本例的游戏行业、夏夜、蓝绿色、便利店场景、三段玩法或编辑拼贴结构变成其他项目的默认值。实际项目必须重新读取 Brief、人物、案例和用户视觉偏好，并打开新的参考原图完成视觉判断。

## 最少充分的完整执行 Prompt

```text
请设计一张 16:9 横版中文游戏达人矩阵招商海报，1920×1080 或同等比例高清尺寸。项目、达人、案例和数据均为完全虚构，仅用于演示。

【主题与背景】
项目主题：夏夜开黑事务所
主题文案：今晚的快乐，由我们组队受理
项目背景：面向暑期游戏节点，用好友开黑、情侣配合和反差挑战，把游戏卖点变成观众一眼能懂的剧情场面。海报需要让客户同时看见达人阵容、三种内容玩法和合作入口。

【具体内容玩法】
1. 好友翻车局
成员：阿岚、九米
案例依据：两人的内容以互怼、临场失误和结尾反转为记忆点。
玩法：两人在便利店门口临时组队挑战新玩法，阿岚负责强行指挥，九米连续误操作，最后由路人一句提示完成反转；游戏的新机制自然成为冲突和笑点来源。
海报短文案：越认真指挥，越容易全队笑场

2. 情侣默契局
成员：小满、迟早
案例依据：账号常用情侣问答、默契测试和输家惩罚。
玩法：把游戏双人任务改造成夏夜默契测试，两人隔着耳机给出相反答案，输家接受清凉饮品惩罚；角色和社交功能自然进入互动。
海报短文案：默契几分，开一局就知道

3. 一人极限局
成员：北桥
案例依据：擅长一本正经挑战高难目标，再用生活化结尾消解紧张。
玩法：北桥在夜班“事务所”受理限时挑战，前半段高强度操作，结尾发现最大的对手是断网倒计时；新地图和限时活动成为挑战目标。
海报短文案：极限操作，也怕最后一分钟

【人物与案例的视觉角色】
五位达人都必须出现且不得重复。阿岚与九米形成左前景冲突动作，小满与迟早在右中景形成耳机连线和相反手势，北桥作为中央第一视觉坐在发光事务台前。人物不是头像网格，要像同处一个夏夜内容现场，并通过视线、动作、道具和光线连接到各自玩法。

三张案例截图分别对应三个玩法，作为“案件证据”自然嵌入桌面夹板、冰柜侧贴和悬挂照片，不遮挡主体；保持可读，不虚构截图里的数据。Logo 位于右上安全区。固定合作信息放在底部：短视频植入｜达人矩阵共创｜节点主题专场。

【完整艺术构图与信息层级】
采用“夏夜便利店 × 剧情事务所”的编辑拼贴场景，不做三栏 PPT。前景用半开的冰柜门、散落任务单和人物交叠建立景深；中景由五位达人和三组玩法形成连续故事；背景是有生活气的街角便利店、夜色和少量招牌光。

第一视觉是中央的北桥和“夏夜开黑事务所”手写招牌；第二阅读锚点是主题文案；随后沿桌面任务单依次读到三个玩法，最后落到底部合作信息。主题区约占画面 20%，人物与场景约占 50%，玩法与案例约占 25%，合作信息约占 5%。信息紧凑但有呼吸感，不留空舞台。

【视觉风格与配色依据】
用户偏好为清爽浅蓝；Brief 的核心情绪是夏夜好友局和轻松解压。主背景使用偏深的夜蓝建立夜晚空间，以薄荷绿和冰柜冷白光呼应清爽偏好，再用西瓜红作为少量笑点和行动提示。材质以磨砂玻璃、旧塑料灯箱、便利店贴纸和纸质任务单为主；光影有明确主光、人物接触阴影和前中后景，不使用霓虹控制台、科技数据流或空洞未来舞台。

【固定信息】
主标题：夏夜开黑事务所
主题文案：今晚的快乐，由我们组队受理
合作信息：短视频植入｜达人矩阵共创｜节点主题专场
不要添加未提供的粉丝量、播放量、报价、客户名称或合作案例。

【关键要求】
最大程度保持五位人物的长相、数量、发型、表情、服装和原始组合，不新增、漏掉或重复人物；案例尽量保持原画面与文字。人物和具体玩法必须处在同一视觉世界里。中文清晰，文字不压脸，安全边距充足。

不要生成竖版或 3:4；不要做 PPT、网页后台、头像网格、等权卡片墙、空背景、空舞台或大块无意义留白；不要只写口号而省略玩法；不要照抄参考案例的标题、Logo、人物排布、专属容器或标志性装饰。

【输出】
只输出一张完整的 16:9 横版招商海报。默认整图生成，一次完成主题、人物、具体玩法、案例、场景和商务信息，不先生成空底图或排布稿。第一视觉清晰，人物尺度大于案例截图，最终图片可直接预览。
```

## 为什么这份 Prompt 足够

- 玩法写清“谁、在哪、发生什么、产品怎样进入”，不是只写标题；
- 人物、案例和 Logo 都有明确视觉角色，但没有把画面锁成坐标表；
- 第一视觉、阅读路径、前中后景和信息比例共同约束构图；
- 配色来自用户偏好和 Brief 情绪，不是因为“游戏就要科技蓝”；
- 禁令只保留这类项目最容易失败的几项，没有重复堆叠。

如果用户明确要求人脸、案例文字、Logo 或固定中文完全不变，应在后台切换严格保真制作；这不是需要用户理解的额外选择。
