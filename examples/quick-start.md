# 快速开始

适用于 Aime、豆包、Codex、Claude Code 等平台。正常只有**两个确认**，不需要懂 Prompt、蒙版或图层，也不需要复制长启动 Prompt。

## 0. 上传后说一句话

在 Aime、豆包或普通会话平台上传完整 Skill 压缩包，然后发送：

```text
请读取这个 Skill，告诉我怎么使用，并带我开始制作一张海报。
```

Skill 自动说明用法并索要人物素材。Aime 使用 Image2；豆包的人物处理和正式海报使用 Seedream 5.0 Pro。

## 1. 安装

Codex 用户直接发送：

```text
请使用 $skill-installer，从 https://github.com/nmmg0112/create-ip-op-poster-skill 安装根目录 Skill，并命名为 create-ip-op-poster。
```

其他 Agent 将完整 Skill 文件夹放入平台规定的 Skills 目录，并保留原有目录结构。

## 2. 上传人物并确认

至少上传人物／动物原图，最好再给每位达人 1—3 张代表案例截图。人物肖像素材好，整张海报的呈现才会好；案例图可以帮助 Agent 从真实内容里提取场景、人物关系、笑点、反转和账号记忆点，让玩法更贴合达人。

支持文件式 Skill 的 Agent 也可以直接发送：

```text
请使用 $create-ip-op-poster，先处理并让我确认人物素材，不要直接做海报。
```

Agent 会给你一张横版白底人物组合预览。只检查长相、数量、身体完整性、重复、遗漏和抠图边缘，不用判断最终海报排版。如果你还没说颜色或感觉，它会在这条消息里顺带问一句；不回答也没关系。没有问题就回复：

```text
人物没问题
```

## 3. 补 Brief、案例和偏好

上传项目 Brief、达人案例、Logo、固定文案和具体建议。案例不一定要放进海报，也可以只用于理解达人内容；没有案例仍能继续，但玩法贴合度有限。

人物确认时可以顺手写 **视觉偏好（可选）**，比如“清爽浅蓝”“暖色活力”“自然松弛”。只回复“人物没问题”也会继续，Agent 会结合 Brief 推荐，不再单独追问。

随后 Agent 会给出一个推荐方案和一个真正不同的备选方案。方案必须写清楚成员、真实依据、内容场景、互动或反转、产品进入方式、第一视觉和整体构图，不能只有口号。

## 4. 选方案并生成

选择推荐方案时回复：

```text
选 1 生成
```

Agent 会直接生成一张 **16:9 横版**完整招商海报，不再要求你选择技术方式或批准长 Prompt，也不会先生成排布稿、空背景或一张和成稿重复的预览。

## 默认整图生成

**默认整图生成**会最大程度保持人物和案例，但可能产生细节变化，**不承诺逐像素**完全一致。

如果人脸、案例截图、Logo、数据或固定中文必须完全不变，请直接把这句话写进需求。Agent 会在后台启用**严格保真**；当前工具无法做到时，只交付方案、Prompt 和素材映射的交接包，不生成低质量替代品。

成图后只增加 Logo、修改准确中文、报价、权益、案例或一个元素时，只允许局部修改，**不得整图重绘**。
