# 结果示例与评测记录

## 业务痛点

机构制作 IP／OP 招商海报时，通常要在多个窗口反复整理 Brief、达人案例、人物素材和生图 Prompt。常见结果是玩法悬浮、竖版误产、海报像 PPT、人物串脸，以及为了改一个标签把整张好图重画。

## 关键链路

```text
上传人物与需求
  -> 确认人物素材
  -> 从 Brief 和案例提炼具体玩法
  -> 视觉导演形成两种方向
  -> 用户选择并锁定当前版本
  -> 平台生图模型一次生成完整 16:9 海报
  -> 实际成图 QA 与成功版本保护
```

## 真实案例 1：四人运动主题

- 输入：4 位人物、运动赛事主题、高张力视觉、两组玩法、中等文字密度。
- 输出：1672×941 PNG，16:9 横版。
- 可观察结果：主题标题、4 位人物、两组玩法和合作信息进入一个完整赛事场景；人物具有主次和前中后景，不是并列头像或 PPT 卡片墙。
- 复盘：第一版整体视觉通过；后续只修改姓名标签时，使用局部修改保留了主体构图。
- 肖像说明：公开 Skill 包不附用户人物原图或成图；参赛说明材料应另附获授权的 Aime 实测截图。

## 真实案例 2：单人高质感美妆

- 输入：1 位人物、热播剧女星与美妆商业主题、高调性、简洁大气，去除干扰人物主体的手部元素。
- 输出：1672×941 PNG，16:9 横版。
- 可观察结果：人物是唯一第一视觉，背景有高级材质、光线和空间层次；文字克制但不空，适合单人招商表达。
- 肖像说明：公开 Skill 包不附人物原图或成图；参赛说明材料应另附获授权的 Aime 实测截图。
