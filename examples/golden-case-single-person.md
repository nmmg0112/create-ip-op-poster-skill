# Golden Case：单人高质感美妆招商海报

## 用途

教 Agent 在低信息量项目中保持高级、简洁但不空。人物为虚构，不附任何真实明星肖像。

## 用户输入

- 单人：虚构女演员林妍；
- 主题：美妆高跑量明星／热播剧女星；
- 风格：高调性、高质感、简洁大气；
- 人物图中出现干扰主体的他人手部，需要从人物素材中去掉；
- 输出：16:9 横版。

## 导演判断

- 人物是唯一第一视觉，使用近景半身而不是把一张竖照缩在角落；
- 简洁来自层级克制，不是空白背景；
- 用香槟金、象牙白、低饱和裸粉和柔和电影光建立美妆高级感；
- 通过半透明织物、细腻皮革／纸张肌理和微弱景深填充空间，不使用廉价亮片和通用粉色渐变；
- 文字只保留主标题、人物定位、一句合作价值和简短合作方式。

## 执行 Prompt

设计一张 16:9 横版单人美妆明星招商海报，虚构人物林妍是唯一第一视觉。主题“入戏入妆”，主题文案“热播角色声量，转化为美妆内容影响力”。内容玩法是从热播角色的妆容记忆点切入，以角色状态、镜头情绪和日常妆面转换自然呈现美妆产品。

使用人物原图的近景半身构成，不改变脸、五官、发型、表情和服装；去掉原图中属于其他人的干扰手部，不补画陌生身体。人物占据画面主要面积，背景不是纯色空板，而是具有象牙白建筑空间、香槟金边缘光、低饱和裸粉半透明织物、细腻纸张和皮革肌理的完整时尚场景。光线柔和但有方向，人物与背景有自然接触和景深。

文字低到中密度，只保留主标题、人物定位、精炼玩法和合作方式。标题现代、克制、有杂志感，不使用廉价亮片、通用粉色渐变、PPT 文本框或大块无意义空白。只输出一张完整 16:9 横版招商海报。

## 成功标准

- 人物是一秒可见的唯一焦点；
- 画面简洁但有材质、光线和空间；
- 文字克制且能够说明商业玩法；
- 去除干扰手部但不改变人物身份；
- 不像 PPT、证件照或简单背景替换。

## 不得固化

不得把象牙白、香槟金、裸粉或明星美妆结构固定为所有单人海报。每次仍需根据人物、行业和 Brief 重新判断。
