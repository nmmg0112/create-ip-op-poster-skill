# ChatGPT／豆包／Coze 启动语

不会安装 Skill 也能用。复制下面整段文字，再上传人物／动物原图。

```text
请按 create-ip-op-poster 的流程协助我制作中文 IP／OP 招商海报。

第一步必须先处理人物素材，不要先做创意方向，也不要直接生成海报。多人物默认使用这条指令：
“把以上人物/动物 拼贴成组合形式，有交叠感，不要并列罗列出来，我要做海报用，横版，其他顺序不重要，横版白底，不要改变任何一个人的长相，抠人物图即可 注意人物不能重复，且人物大小调整一致一些”

人物阶段请同时准备：
1. 横版白底组合预览图；
2. 相同排布的透明底人物总图；
3. 每个人物／动物或不可拆原始组合的独立透明抠图。

请检查人物／动物数量、长相、组合关系、边缘、大小、交叠、遮挡、重复、遗漏、家具残边和大块空洞。完成后停下来，等我回复“人物素材通过”。这个确认只确认人物素材可用，不锁死最终海报排布。

人物素材通过后，再读取我提供的 Brief、账号特征、案例截图、Logo 和建议，给出 2—3 个真正不同的主题／玩法方向，同时让我选择：

模式 A｜快速生图：生图模型直接完成整张海报，速度快、整体感强，但人物、截图、Logo 和中文可能被重绘，不能承诺原样保留。

模式 B｜保真合成：生图模型先生成完整的 PNG、WebP 或 JPEG 艺术底图，包含场景、构图、材质、光影、前中后景和视觉动势；再把确认过的人物透明图、完整案例截图、原 Logo 和准确中文作为保护图层覆回。模式 B 不能使用 SVG、HTML、PPT、Canvas、Sharp、固定色块或头像网格生成底图，程序只能在生图底图产生后做图层合成和验证。

选定方向和模式后，请展示实际使用的完整文字 Prompt。Prompt 要写清主题、项目背景、玩法、成员、案例对应关系、信息层级、视觉母题、颜色、材质、景深、保护图层、负面要求和验收条件。不要生成排布确认稿。等我回复“确认生成”后，默认只正式生图一次；除非我明确要求重做，否则不要自动消耗第二次生图。

人物素材处理阶段不许新增、遗漏、重复或改变人物／动物身份。模式 B 不许改写、裁切或重绘案例截图，也不许改变 Logo；模式 A 必须先逐项列出允许生成式重绘的素材，并明确不能承诺原样保留。任何模式都不许虚构数据、客户、报价或合作权益。参考海报只学习结构、密度和气质，不能照抄。

如果当前平台没有生图能力，请输出完整 Prompt 和素材映射交接包，不得使用 SVG、HTML、PPT 或程序化信息板冒充最终海报。
```

常用回复：

```text
人物素材通过
选方向 1，用模式 B
确认生成
```
