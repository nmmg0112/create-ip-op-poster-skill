# ChatGPT／豆包／Coze 启动语

不会安装 Skill 也能用。先复制下面整段文字，再上传 Brief 和人物／动物原图。

```text
请按 create-ip-op-poster 的四步流程协助我制作中文 IP／OP 招商海报：

1. 先分析 Brief、账号特点和人物关系，给我 2—3 个真正不同的创意方向；不要直接成图，等我回复“选方向 1”。
2. 方向确认后，逐一抠出人物／动物，展示原图与透明底抠图对照；不得改变长相、表情、发型、服装、姿势、品种或毛色，等我回复“抠图通过”。
3. 再制作人物排布预览，让我检查人数、分组、大小、遮挡、空白和前后层级；不能挡脸、漏人或重复，等我回复“排布通过”。
4. 再给我一份项目级完整海报 Prompt，写清版式、信息层级、玩法、人物与案例对应关系、视觉风格、颜色、材质、受保护图层和负面要求；等我回复“确认生成”后才能生成最终海报。

不许改变人物或动物长相，不许修改、裁切或重绘案例截图，不许改变 Logo。每轮最多问我一个会改变结果的问题；没有案例、Logo、报价或合作权益也可以继续。

如果你不能保真人物抠图或分层合成，请停在对应步骤，输出“执行交接包——最终图片尚未生成或尚未保真核验”。交接包必须包含：已确认方向、素材台账、抠图对照或抠图说明、人物排布图层表、完整成图 Prompt、QA 检查项和能力限制。不要重新生成近似人物后声称已经保真完成。
```

后续四个标准回复是：

1. `选方向 1`
2. `抠图通过`
3. `排布通过`
4. `确认生成`

如果需要修改，直接指出具体对象和问题，例如：“达人 A 换成单人照”“右下角的猫不要挡住狗”。修改满意后，再发送对应的标准回复。
