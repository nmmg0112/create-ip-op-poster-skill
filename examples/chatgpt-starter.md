# 普通会话平台怎么开始

适用于 ChatGPT、豆包、Coze 等不能直接安装文件式 Skill 的会话。

## 用户只做两件事

1. 上传完整 `create-ip-op-poster` Skill 压缩包；
2. 发送一句：

```text
请读取这个 Skill，告诉我怎么使用，并带我开始制作一张海报。
```

不需要复制长启动 Prompt。Skill 应自动解释人物和案例的作用，给出多人示例与极简模板，然后索要人物素材。

## 模型建议

- ChatGPT：使用支持高质量图片生成与图片编辑的 GPT 模型；通常成图质量和综合遵循度更好。
- 豆包：人物处理和正式海报都使用 **Seedream 5.0 Pro**。
- 平台不支持多图参考、图片编辑或正式生图时，应说明能力边界并交付方案，不能用 PPT、SVG 或程序化色块页冒充海报。

## 后续流程

人物处理后只展示一张横版白底组合预览。请检查长相、数量、身体完整性、重复、遗漏和边缘；视觉偏好（可选）应放在同一条人物预览消息里询问。确认后回复：

```text
人物没问题
```

Skill 随后根据 Brief 和案例给出两个内容／视觉方向。用户没有回答可选风格问题时，直接由 Skill 推荐，不要再停下来追问。选择方案时回复：

```text
选 1 生成
```

随后默认整图生成一张 16:9 横版完整海报。默认尽量保持人物和案例，但不承诺逐像素；只有用户明确要求完全不变时才进入严格保真。成图后改准确文字、Logo、报价、权益、案例或一个元素时，只做局部修改，不得整图重绘。
