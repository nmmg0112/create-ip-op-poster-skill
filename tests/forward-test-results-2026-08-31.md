# 2026-08-31 生图优先流程独立测试记录

本文件只记录新版流程的直接证据。未真实运行或缺少图像／调用记录的项目必须保持 `NOT VERIFIABLE`，不能用静态规则代替行为证据。测试材料使用授权素材，提交记录只保留匿名 `Pxx/Cxx/Lxx` 编号，不保存本地绝对路径。

## person_first

- 目标：验证只收到人物／动物原图时，先产出人物素材并等待 `人物素材通过`，不先要求 Brief、方向或模式。
- 预期停止阶段：`person_material_pending`；不得出现海报排布确认门槛。
- 必须检查：横版白底组合预览、透明底人物总图、独立透明抠图、人数、身份、重复、遗漏、遮挡和边缘；记录每类产物格式、尺寸、透明通道与稳定 ID。
- 正式海报生图次数：`0`；人物素材处理不计入正式海报生图。
- 失败路由：人物身份、数量、边缘或透明通道失败时仍停在 `person_material_pending`；能力不足时进入 `handoff`。
- 当前结果：`NOT VERIFIABLE`。
- 原因：新版 Skill 尚未完成独立对话前向测试。

## mode_a_one_generation

- 目标：验证人物素材通过后，模式 A 清楚披露重绘风险；每次 Prompt 新增或修改后都完整展示当前版本，并在 `确认生成` 后只进行一次正式海报生图。
- 必经停止阶段：`prompt_pending`；不得出现海报排布确认门槛。成功终态为 `complete`。
- 必须检查：完整文字 Prompt、风险披露、完整海报预览、最终文件、明显错脸／漏人／乱码，以及是否自动重试。
- 正式海报生图次数：默认恰好 `1`；确认 Prompt 的文字轮次为 `0`。
- 失败路由：生成失败后停在 `qa` 或负责阶段，先报告问题，不自动调用第二次正式生图。
- 当前结果：`NOT VERIFIABLE`。
- 原因：新版 Skill 尚未完成独立对话前向测试。

## mode_b_bitmap_then_layers

- 目标：验证模式 B 第一项生产动作是生图模型生成 PNG、WebP 或 JPEG 位图底图，随后才覆回人物、截图、Logo 和固定中文。
- 必经停止阶段：`prompt_pending`；不得出现海报排布确认门槛。成功终态为 `complete`，无法合成时为 `handoff`。
- 必须检查：底图文件与真实格式、生成工具／模型记录、先后顺序、保护图层表、非目标区域、完整海报预览和最终视觉质量。
- 正式海报生图次数：默认恰好 `1`；必须记录 `visual_base_path`、`visual_base_format`、`image_generation_model_or_tool` 与 `visual_base_created_before_composite`。
- 失败路由：程序化底图或顺序不可验证时停在 `production`；缺少所需能力时进入 `handoff`，不得伪装完成。
- 当前结果：`NOT VERIFIABLE`。
- 原因：新版 Skill 尚未完成独立对话前向测试。

## no_imagegen_no_svg_fallback

- 目标：验证平台没有生图能力时只输出完整 Prompt、素材映射和交接包，不用 SVG、HTML、PPT 或程序化信息板冒充最终海报。
- 预期停止与终态：从首次能力判断直接进入 `handoff`；不得要求海报排布确认或再次经过 `prompt_pending`。
- 必须检查：能力说明、三类人物素材记录、完整 Prompt、素材映射、目标位图格式、保护图层清单、当前 QA、下一执行工具要求，以及是否错误声称已生成海报。
- 正式海报生图次数：`0`。
- 失败路由：若输出程序化底图、伪最终海报或声称素材已保真通过，场景直接 `FAIL`。
- 当前结果：`NOT VERIFIABLE`。
- 原因：新版 Skill 尚未完成独立对话前向测试。
