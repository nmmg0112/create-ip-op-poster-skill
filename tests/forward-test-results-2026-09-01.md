# 2026-09-01 精简交互独立前向测试

本轮只验证用户反馈直接涉及的两项交互合同，不用静态规则代替真实海报生产证据。测试 Agent 只收到当前 Skill、当前阶段所需资料和自然语言任务，没有收到预期答案。

## person_material_single_review

- 输入：只提供 6 位获授权达人原图，Brief 和案例稍后补。
- 实际输出：先解释人物肖像与案例图的用途；默认只承诺向用户展示一张横版白底组合预览。
- 后台行为：保留同排布透明底人物总图；独立透明抠图只在单独移动、重新分组、遮挡修复或局部替换时按需生成。
- 确认门槛：只要求回复 `人物素材通过`，不要求用户逐一确认三份人物文件，不进入创意方向或海报生产。
- 阶段与计数：`person_material_pending`；`formal_generation_count: 0`。
- 结果：`PASS`（交互合同）。本轮为纯文本路由测试；身份、数量、透明通道和边缘生产能力沿用 2026-08-31 已记录的实际素材测试证据。

## compact_generation_card

- 输入：人物素材已通过；项目“新机搭子已就位”；方向“生活搭子接力”；模式 B；达人 P01/P02；案例 C01/C02；Logo L01；用户要求继续到生成前确认。
- 实际输出：只展示一屏 `生成确认卡`，包含主题、项目背景、达人玩法、第一视觉／构图、配色风格、案例／Logo、生成方式和保真边界。
- 未出现：完整执行 Prompt、排布预览、第二次确认门槛或正式海报生图。
- 可选展开：完整执行 Prompt 仅在用户明确回复 `查看完整 Prompt` 时展示；后台仍保留可直接执行的完整版本。
- 阶段与计数：`prompt_pending`；`formal_generation_count: 0`；下一步唯一确认回复为 `确认生成`。
- 结果：`PASS`。

## 结论

当前 Skill 已把“执行 Prompt 不是越长越好”落实为交互合同：内部 Prompt 保持最少充分、优先级清楚、无重复冲突；用户默认只看一屏确认卡。人物阶段也从固定三份可见产物改为“一张可见预览 + 后台透明总图 + 按需独立抠图”。
